## Features

- Dark theme by default, with an explicit light-mode toggle (not tied to OS preference)
- Custom cursor, scroll-triggered reveal animations (GSAP + ScrollTrigger), and a typed-text role rotator
- Full-text search overlay (press `/`) across all sections
- Optional 3D "room" navigation mode
- Fully responsive, with `prefers-reduced-motion` and `prefers-contrast` support
- Accessible: skip-nav link, ARIA labels throughout, keyboard-navigable
- SEO-ready: Open Graph tags, Twitter Card tags, and JSON-LD structured data

## Tech stack

Vanilla HTML5, CSS3, and JavaScript — no framework. Uses:
- [GSAP](https://gsap.com/) + ScrollTrigger for animations
- [Typed.js](https://github.com/mattboldt/typed.js/) for the role text rotator
- [Font Awesome](https://fontawesome.com/) for icons not replaced with inline SVG
- [Formspree](https://formspree.io/) for the contact form backend

## Running locally

No build step required — just open `index.html` in a browser, or serve it with any static file server:

```bash
npx serve .
```

## Deployment

Deployed on [Vercel](https://vercel.com/) as a static site. Any push to `main` on this repository triggers an automatic redeploy.
